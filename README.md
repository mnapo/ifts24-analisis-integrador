# Análisis Integrador — Indicadores de desarrollo en América Latina

Proyecto académico para el Trabajo Final de Desarrollo de un Reporte en Power BI. Compara Argentina, Brasil, Chile y Uruguay con indicadores públicos del Banco Mundial para 2024.

## Dashboard Next.js
Consume el mismo CSV que Power BI y presenta comparación de uso de Internet y desempeño estadístico, filtros, gráficos, tabla y exportación CSV.

## Dataset
`public/data/indicadores-banco-mundial.csv` (8 observaciones: 4 países × 2 indicadores).
- `IT.NET.USER.ZS`: personas que utilizan Internet (% población).
- `IQ.SPI.OVRL`: Statistical Performance Indicators, puntaje 0–100.

Fuente: [World Bank Open Data](https://data.worldbank.org/).

## Proyecto Power BI
Abrir `powerbi/IndicadoresLatam.pbip`. Modelo semántico: FactIndicadores, Paises e Indicadores. Ver `docs/POWER-BI.md`.
