# Presentación interactiva

La entrega se desarrolla como una presentación web en Next.js. No requiere un modelo ni un informe de Power BI.

## Navegación

- Una diapositiva ocupa la pantalla disponible (100svh).
- Carrusel con flechas anterior/siguiente.
- Indicadores inferiores clicables.
- Teclas izquierda/derecha, PageUp/PageDown, Home y End.
- Transiciones entre diapositivas.
- Diseño adaptable a pantallas móviles.

## Guion

1. Portada y pregunta de investigación.
2. Panorama regional.
3. Respuestas gubernamentales y economía.
4. Impacto sanitario y social.
5. Recuperación económica.
6. Fuentes, datos y cobertura.
7. Metodología y limitaciones.
8. Resultados y conclusiones.

Los gráficos y cifras se incorporarán cuando el ETL haya generado datasets y superado los controles de calidad. No se deben mostrar valores de ejemplo como resultados reales.
